## 2024-10-29 - Missing Output Encoding in JavaScript Escaping Functions
**Vulnerability:** The HTML escaping functions (`esc`, `escHtml`) in multiple JS files (`app.js`, `jobsearch.js`, `tailor.js`, `rank.js`, `improve-all.js`) were incomplete. They failed to properly escape single quotes (`'`) and forward slashes (`/`).
**Learning:** Incomplete HTML escaping can lead to attribute-based Cross-Site Scripting (XSS) when untrusted input is interpolated into HTML attributes wrapped in single quotes, or when complex payload structures involve forward slashes. Custom escaping logic is prone to omission compared to standard built-in functions.
**Prevention:** Always ensure comprehensive character escaping (`&`, `<`, `>`, `"`, `'`, `/`) when implementing custom HTML encoding functions for dynamically injected content to mitigate XSS risks.
