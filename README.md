# CVKita 🇮🇩

CV builder gratis untuk fresh graduate Indonesia — bikin CV lolos ATS dalam 5 menit, export PDF tanpa watermark.

## Fitur
- ✅ Form 6 seksi: Data Diri, Pendidikan, Pengalaman (magang/organisasi), Project, Keahlian, Prestasi
- ✅ Live preview dua kolom (desktop) / bertumpuk (mobile-first)
- ✅ 3 template ATS-friendly: Classic, Modern, Minimal
- ✅ Export PDF gratis via print — tanpa watermark, tanpa batas
- ✅ Autosave localStorage — data 100% di perangkat user, tanpa server
- ✅ Isi dalam Bahasa Indonesia → output CV berbahasa Inggris (ATS-ready)

## Stack
HTML + CSS + vanilla JS. Nol dependensi, nol build step, nol server.

## Jalankan Lokal
```bash
python3 -m http.server 8090
# buka http://localhost:8090
```
